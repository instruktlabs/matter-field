# Code of Conduct

Matter Field is a small technical project built around careful measurement.
We want participation to be rigorous, welcoming, and safe for people with
different backgrounds and levels of graphics experience.

## Expected behavior

- Be respectful, specific, and patient.
- Critique claims, measurements, and code without attacking people.
- State uncertainty and distinguish reproduced facts from inference.
- Welcome corrections, especially when they narrow an overbroad claim.
- Give contributors credit and respect licensing and attribution.
- Avoid pressuring anyone to reveal private identity, employer, hardware, or
  machine information.

## Unacceptable behavior

- Harassment, threats, discriminatory language, or unwanted sexual attention.
- Personal attacks, sustained disruption, or deliberate humiliation.
- Publishing another person's private information without permission.
- Falsifying receipts, benchmarks, identities, or reproduction results.
- Using project spaces to promote unrelated products, spam, or scams.

## Scope

This code applies in repository issues, pull requests, discussions, project
events, and other spaces where someone is representing Matter Field or
Instrukt Labs LLC.

## Enforcement

Project maintainers may edit or remove contributions, lock conversations,
issue warnings, or temporarily or permanently restrict participation when
behavior threatens the project or its participants. Responses should be
proportionate, documented privately when practical, and focused on preventing
further harm.

Report conduct concerns privately through the contact method listed on the
[Instrukt Labs GitHub organization profile](https://github.com/instruktlabs).
Do not open a public issue that exposes the affected person. If immediate
safety is at risk, contact the appropriate local service rather than waiting
for project maintainers.
